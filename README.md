# Artist OS

A desktop-style workspace for a working studio. Phase 1 ships one tool:
**Commission Documents** — quote a piece, record a deposit, and print a
polished document for the client, online or off.

```bash
npm install
npm run dev
```

See **[PROJECT_GUIDE.md](PROJECT_GUIDE.md)** for architecture, commands,
decisions and current blockers. `COMMISSION_PHASE_1.md` is the original brief.
